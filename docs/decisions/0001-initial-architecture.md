# 0001. 초기 학생 앱과 공개 콘텐츠 경계

- 상태: 첫 개발 버전에 적용한 기본 선택. 사용자와 논의 후 변경 가능.
- 기준: PRD v0.2, 특히 ST-01~16, 데이터 모델 8절, 품질 요구 10절.

## 기술

React + TypeScript + Vite로 학생 웹앱을 시작한다. Node.js 24와 npm lockfile을 사용한다. 데이터 검증은 Zod, 도메인 테스트는 Vitest, 브라우저 검증은 Playwright를 사용한다. 초기 선택에서는 호스팅을 분리했으며, 이후 사용자 선택으로 학생 앱의 GitHub Pages 호스팅을 결정했다. [결정 0002](0002-github-pages.md)를 따른다.

현재 학생 앱은 정적 공개 데이터만 읽으므로 서버나 API 키가 필요 없다. 이후 교사 작성·공개 기능에는 인증된 서버와 영속 저장소가 필요하며, 학생 번들에 관리자 권한을 추가하는 방식으로 구현하지 않는다.

## 콘텐츠

- 최초 서비스명은 Know or Nope였으며, [PRD v0.3](../prd/flip-it-prd-v0.3.md)에서 `flip-it`으로 변경했다.
- 국어·수학의 샘플 공개 단어장 3개, 카드 20개로 시작했고 v0.3에서 단어장당 50개로 확장했다. 실제 교사 검수를 완료한 교육 자료가 아니다.
- 도식은 로컬 SVG이며 원격 폰트·이미지 API에 의존하지 않는다.
- 학생 데이터 스키마는 공개 단어장만 허용하며, 누락된 참조·중복 카드 ID·어느 공개 단어장에도 속하지 않는 카드를 거부한다.
- 현재 스키마 검증은 CMS 접근 통제나 실제 게시 파이프라인을 대체하지 않는다. 초안과 검수 자료는 학생 번들에 넣지 않아야 한다.
- 그림은 선택 사항이며, 없는 경우 단어·설명 두 영역으로 학습한다.

## 학습 정책

- 기본값은 전체 카드, 무작위이다. 초기의 단어 가림 / 그림·설명 표시를 v0.3에서 단어 표시 / 그림·설명 가림으로 변경했다. 이미 진행 중인 회차의 표시 설정은 유지한다.
- 시작 시 선택 카드, 순서, 프리셋, 카드 내용과 버전을 회차에 고정한다. 무작위 순서는 회차 시작 때 한 번만 생성한다.
- 저장한 카드 내용의 스냅샷으로 진행 중·과거 회차를 재현한다. 콘텐츠가 바뀌면 기존 회차는 시작 당시 내용으로 이어가고 새 회차에서 새 내용을 읽는다.
- 최초 표시가 전부 가려지거나, 그림 없는 카드를 그림만 표시하도록 설정하면 시작을 막는다.
- 학습 중에는 세 영역을 모두 잠시 가리는 동작을 허용한다. 각 영역의 보이기 버튼은 항상 남는다.
- 카드 이동 시 프리셋을 다시 적용한다. 영역을 열어본 상태는 저장하지 않는다.
- 마지막 카드로 이동하거나 결과 화면을 보는 것만으로 완료하지 않는다. `학습 완료하고 기록 저장`이 회차를 종료한다.
- 완료 전 새 회차를 시작하면 기존 진행을 교체한다. 교체 전에 확인한다.
- 알고 있는 비율의 분모는 판정한 카드 수이며, 판정 0개는 `—`이다.

## 로컬 보관

- `know-or-nope:progress:v1`에 단어장별 진행 중 회차와 최근 20회 완료 스냅샷을 저장한다.
- 읽기·스키마 검증 실패 시 기존 원문을 자동 덮어쓰지 않는다. 사용자가 초기화하기 전까지 새 학습은 메모리에만 유지된다.
- 쓰기 실패 시 메모리에서 계속 학습할 수 있지만 새로고침·종료 시 유실 가능성을 알린다.
- 동시 탭 간 병합·동기화와 내보내기는 이번 구현에 포함하지 않는다. 마지막 쓰기가 남는 제한을 기록 화면에 안내한다.
