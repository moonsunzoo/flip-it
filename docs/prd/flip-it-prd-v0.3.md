# flip-it PRD v0.3 — 첫 번째 피드백

- 기준일: 2026-10-22 (한국 시간)
- 상태: 사용자 피드백으로 확정된 변경 사항
- 이전 원문: [Know or Nope PRD v0.2](know-or-nope-prd-v0.2.md)

이 문서는 v0.2의 아래 항목을 개정한다. 명시하지 않은 기능 요구사항과 교사 운영·이미지 생산 P0 범위는 v0.2를 그대로 따른다. 첨부된 v0.2 파일은 수정하지 않는다.

## 변경 사항

| 항목              | 확정 내용                                                                                                                          | 관련 요구·수용 기준         |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| 서비스명          | 이전 이름 Know or Nope를 `flip-it`으로 변경한다. 화면의 브랜드, 브라우저 제목, 설명, 아이콘과 현재 안내 문서에 적용한다.           | 제품 개요, AT-ST-01         |
| 첫 화면           | 상단의 큰 소개 영역, 장식 카드, `오늘의 학습 시작` 버튼, `로그인 없이, 내 속도대로` 문구를 제거하고 과목·단어장 선택부터 보여준다. | S01, ST-01~03, AT-ST-01~02  |
| 새 학습 초기 표시 | 단어 ON, 그림 OFF, 설명 OFF를 기본값으로 한다. 사용자가 설정에서 각각 변경할 수 있다.                                              | S02, ST-06, ST-08, AT-ST-06 |
| 샘플 확대         | 기존 문학·문법·도형 단어장별로 50개씩, 총 150개 개념 카드를 제공한다. 정의와 간단한 예문을 포함한다.                               | ST-02, ST-04, AT-ST-04      |

## 보존 및 범위

- 이름 변경으로 기존 브라우저의 진행 중 학습이나 완료 이력이 사라지지 않아야 한다.
- 기존 카드 ID를 유지한다. 콘텐츠가 늘어나도 진행 중 회차는 저장 당시 카드와 표시 설정을 사용한다. 새 회차부터 새 콘텐츠와 기본 표시 설정을 적용한다.
- 단어장의 구분은 기존 세 단어장으로 해석했다. 문학은 표현법·시·소설, 문법은 품사·단어·문장, 도형은 평면·입체 개념을 포함한다.
- 샘플은 개발 과정에서 작성한 예시이며 교사가 제공하거나 검수한 자료가 아니다. 그림은 선택 사항으로 유지한다.
- 교사용 편집, 인증, 다건 가져오기, 이미지 일괄 생산과 검수 기능을 이번 피드백 범위에 추가하지 않는다.

## 추가 수용 기준

1. 첫 화면의 서비스명은 `flip-it`이며 과목·단어장 목록 위에 이전 소개 영역이 없다.
2. 세 단어장이 각각 50장을 표시하고, 개별 선택과 주제별 선택으로 학습할 수 있다.
3. 새 학습 설정에서 단어만 켜져 있고, 학습을 시작하면 그림과 설명은 가려져 있다.
4. 설명이나 그림을 열어도 단어의 표시 상태는 독립적으로 유지된다. 다음 카드와 새로고침에서는 회차의 초기 표시 설정을 적용한다.
5. 이전 버전에서 저장된 회차의 카드·표시 설정·판정과 완료 이력이 이름 변경 후에도 그대로 복원된다.
