# flip-it PRD v0.4 — 모바일 중심 학습 흐름

- 기준일: 2026-10-22 (한국 시간)
- 상태: 두 번째 사용자 피드백으로 확정된 변경 사항
- 이전 기준: [PRD v0.2 원본](know-or-nope-prd-v0.2.md) + [v0.3 변경 사항](flip-it-prd-v0.3.md)

모바일을 주 사용 환경으로 삼는다. 이전 버전의 학습 범위, 데이터 보존, 교사 운영·이미지 생산 P0 요구사항은 유지한다.

## 확정된 요구사항

| 항목          | 변경 내용                                                                                                                | 관련 요구·수용 기준   |
| ------------- | ------------------------------------------------------------------------------------------------------------------------ | --------------------- |
| 모바일 우선   | 주요 버튼과 학습 동선을 모바일 터치 조작에 맞춘다. 데스크톱에서도 같은 흐름을 제공한다.                                  | ST-20, AT-ST-12       |
| 스와이프 탐색 | 알고 있음·모름 선택 후 이전·다음 버튼 또는 좌우 스와이프로 카드를 넘길 수 있다. 판정 없이 이동하는 기존 동작도 유지한다. | ST-09~11, ST-20       |
| 첫 카드 안내  | 첫 카드에서만 스와이프로 넘길 수 있음을 알려준다. 이후 카드에서는 반복하지 않는다.                                       | ST-20                 |
| 단계별 설정   | 단어장 진입 후 설정을 한 화면에 나열하지 않고, 한 항목을 설정한 뒤 다음 화면으로 이동한다.                               | ST-03~06, AT-ST-02~06 |

## 구현 선택

- 설정은 학습 범위 → 카드 순서 → 처음 보일 영역의 3단계다. 상단에 진행 단계를 표시하고 아래에 이전 설정·다음·학습 시작 버튼을 둔다. 단계 이동 시 선택 값을 유지하고 제목에 초점을 옮긴다. 새로고침하면 설정 초안은 초기화하며, 저장된 학습 회차는 유지한다.
- 작은 화면에서는 주요 조작 영역을 하단에 붙이고 버튼의 터치 영역을 최소 44px로 제공한다. 긴 카드·선택 목록은 세로로 스크롤할 수 있다.
- 카드 위에서 왼쪽으로 밀면 다음, 오른쪽으로 밀면 이전 카드로 이동한다. 터치 제스처만 처리하고 마우스 조작은 기존 버튼을 사용한다. 수평 이동 56px 이상이며 수직 이동보다 충분히 큰 제스처를 인식한다. 세로 스크롤, 짧은 드래그, 취소된 터치, 여러 손가락의 터치는 이동으로 처리하지 않는다. 브라우저 확대를 막지 않는다.
- 첫 카드에서 알고 있음·모름을 선택하면 터치 기기에 안내를 표시한다. 안내를 닫거나 다른 카드로 이동하면 해당 회차에서는 다시 표시하지 않는다. 이를 선택적 회차 필드로 저장하여 기존 기록을 읽을 수 있다. 카드가 한 장뿐이면 안내하지 않는다.
- 스와이프는 판정을 변경하거나 자동 완료하지 않는다. 첫 카드 이전·마지막 카드 다음으로는 이동하지 않는다. 마지막 카드에서는 결과 보기와 명시적 완료 흐름을 유지한다.

## 수용 기준

1. 360px 화면에서 한 번에 한 설정 단계만 보이며, 다음·이전 이동 후에도 범위·순서·표시 선택이 유지된다.
2. 0장 선택 시 다음 단계로 갈 수 없고, 모든 영역 숨김 또는 그림 없는 카드의 그림 전용 프리셋으로 학습을 시작할 수 없다.
3. 스와이프 후 현재 위치·판정이 저장되고, 새 카드의 영역 표시는 회차 초기 프리셋으로 돌아간다. 버튼으로도 동일하게 이동한다.
4. 세로 스크롤·짧은 드래그·터치 취소는 카드를 넘기거나 가려진 영역을 실수로 열지 않는다. 스와이프 후 키보드로 영역을 열 수도 있다.
5. 첫 카드 안내는 두 번째 카드 이동 후, 첫 카드 복귀 및 새로고침 후에도 반복하지 않는다.
6. 첫 카드·마지막 카드 경계를 넘거나 학습을 자동 완료하지 않는다. 기존 회차·완료 이력도 그대로 복원한다.
