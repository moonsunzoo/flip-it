# flip-it PRD v0.5 — 버튼 중심 카드 탐색

- 기준일: 2026-10-22 (한국 시간)
- 상태: 스와이프 품질 피드백과 사용자가 허용한 제거 대안에 따른 구현 결정
- 이전 기준: [PRD v0.4](flip-it-prd-v0.4.md), [v0.3](flip-it-prd-v0.3.md), [v0.2 원본](know-or-nope-prd-v0.2.md)

## 판단 근거

v0.4의 스와이프는 손가락을 따라가는 시각적 움직임 없이, 손을 뗄 때 거리 기준을 충족하면 카드를 교체한다. 기존 위로 나타나는 효과도 수평 제스처와 맞지 않았다. 자동 테스트는 이동 결과와 데이터 보존을 검증했으나 손에 따라오는 조작 품질을 보증하지 않았다.

개선에는 드래그 추종, 속도·거리 기반 전환, 취소 시 복귀, 세로 스크롤과의 방향 구분이 함께 필요하다. 기술적으로 가능하지만, 이 화면은 그림·설명의 공개 상태에 따라 높이가 달라지고 세로 스크롤이 필요하다. 하단 버튼으로 같은 탐색을 할 수 있으므로 현재 제품에서는 스와이프를 제거하는 대안을 선택한다. 감도 수치만 조정하는 개선은 하지 않는다.

## 변경 사항

- ST-09, ST-20: 카드 위의 터치 제스처로 이전·다음 카드를 넘기지 않는다. 스와이프 안내와 전용 이벤트·클릭 억제·터치 동작 제한을 제거한다.
- AT-ST-12: 모바일 이전·다음 버튼을 뷰포트 하단에 고정한다. 카드 높이, 판정, 내용 표시, 세로 스크롤에 따라 버튼 위치가 이동하지 않는다. 버튼 높이는 최소 48px이며 기기 하단 안전 영역을 반영한다.
- 고정 탐색부가 본문이나 푸터의 마지막 내용을 가리지 않도록 하단 공간을 확보한다. 모바일 판정 버튼은 카드 아래에 둔다.
- 카드 교체 시 위로 나타나는 효과를 없앤다. 첫 카드의 이전 버튼 비활성화, 마지막 카드의 결과 보기, 명시적 완료는 유지한다.
- v0.4의 3단계 설정, 기존 회차·판정·스냅샷·이력은 유지한다. 이전 저장 데이터의 선택적 안내 필드는 호환성을 위해 읽고 보존하되 새 회차에서 생성하거나 갱신하지 않는다.

## 수용 기준

1. 좌우 드래그·세로 스크롤로 현재 카드나 판정이 바뀌지 않고 스와이프 안내가 나타나지 않는다.
2. 이전·다음 버튼으로 이동하면 회차 초기 표시가 적용되고 판정·순서·현재 위치가 저장 및 복원된다.
3. 360px 화면과 낮은 640px 화면에서 탐색 버튼이 하단의 같은 위치에 유지된다. 페이지 끝까지 스크롤했을 때 푸터도 탐색부 위에서 볼 수 있다.
4. 기존 스와이프 안내 필드가 있는 저장 데이터도 회차와 완료 이력을 그대로 복원한다.
