# PRD 관리

현재 기준은 [원본 PRD v0.2](know-or-nope-prd-v0.2.md)에 [flip-it PRD v0.3 변경 사항](flip-it-prd-v0.3.md)을 적용한 요구사항입니다. 사용자 첨부 원본은 내용 변경 없이 보관합니다.

## 운영 규칙

1. 기존 버전은 원본으로 유지합니다. 합의한 요구사항 변경은 `know-or-nope-prd-v0.3.md`처럼 새 버전에 반영합니다.
2. 구현 편의로 PRD의 `[제안]`이나 `[미결정]`을 `[확정]`으로 바꾸지 않습니다.
3. 구현 과정에서 선택한 기본값·기술은 `docs/decisions/`에 기록하고, 제품 합의와 구현 선택을 구분합니다.
4. 기능별 완료 여부, 검증 근거, 남은 항목은 [구현 현황](../implementation-status.md)에 기록합니다.
5. 변경 버전에는 변경 이유와 영향받는 요구사항·수용 테스트 ID를 남깁니다.

| 버전 | 상태                                         | 파일                       |
| ---- | -------------------------------------------- | -------------------------- |
| v0.2 | 최초 첨부 원본                               | `know-or-nope-prd-v0.2.md` |
| v0.3 | 현재 개정 · 이름·첫 화면·초기 표시·샘플 확대 | `flip-it-prd-v0.3.md`      |

첨부 파일명: `know-or-nope-prd-v0.2.md`. 문서의 기술 예시와 제안은 검토 대상이며, 외부 서비스 사용이나 배포에 대한 실행 지시로 해석하지 않습니다.
