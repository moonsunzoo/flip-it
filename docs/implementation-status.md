# 구현 현황

현재는 **학생 학습 흐름의 첫 개발 버전**이다. PRD Phase A 전체와 수업 투입 조건은 아직 충족하지 않는다.

두 번째 피드백의 모바일 학습 흐름을 **[GitHub Pages](https://moonsunzoo.github.io/flip-it/)에 배포 완료**했다. 2026-10-22 21:50 (한국 시간)에 게시했으며, 공개 사이트의 데스크톱·모바일 E2E 28개가 모두 통과했다.

## 구현 범위

두 번째 사용자 피드백([PRD v0.4](prd/flip-it-prd-v0.4.md))을 반영했다. 학습 설정을 범위·순서·초기 표시의 3단계로 나누고, 모바일 하단 조작부와 44px 이상 터치 영역을 적용했다. 카드 좌우 스와이프, 첫 카드 판정 시 회차당 한 번의 안내, 안내 상태의 저장·복원을 추가했다. 세로 스크롤과 확대, 기존 판정·스냅샷·명시적 완료는 유지한다.

첫 번째 사용자 피드백([PRD v0.3](prd/flip-it-prd-v0.3.md))을 반영했다. 서비스명을 `flip-it`으로 변경하고 첫 화면의 소개·학습 시작 영역을 제거했다. 새 회차의 초기 표시는 단어 ON·그림 OFF·설명 OFF이다. 문학·문법·도형 단어장은 각 50개, 총 150개로 확대했다. 기존 카드 ID, 저장 키와 진행 중 회차의 스냅샷·표시 설정을 유지한다.

## 검증 항목

두 번째 피드백 버전: 타입 검사, 단위 테스트 17개, `/flip-it/` 빌드와 데스크톱·모바일 E2E 28개 통과. 실제 브라우저 터치 입력으로 이동·취소·세로 제스처·짧은 드래그를 검증했다. 단계별 선택 보존·검증, 첫 카드 안내와 이전 기록 복원을 포함한다. 360px 모바일 설정 3단계·학습 화면과 데스크톱 설정을 시각 확인했다. 원격 CI의 `/`와 `/flip-it/` 검사, Pages 게시, 공개 사이트의 E2E 28개도 모두 성공했다.

첫 번째 피드백 버전의 로컬 검증: 포맷·타입 검사, 단위 테스트 17개, `/flip-it/` 빌드와 데스크톱·모바일 E2E 22개 통과. 첫 화면과 360px 학습 화면을 시각 확인했고 가로 넘침이 없다. 기존 버전의 회차·완료 이력 복원, 새 단어 전용 초기값, 그림 토글과 새로고침을 검증했다. 첨부 PRD v0.2의 SHA-256은 그대로다. 원격 배포도 성공했으며 공개 사이트를 대상으로 같은 E2E 22개가 모두 통과했다.

새 환경은 Node.js 24.19.0, npm 11.9.0, Chromium 154.0.8037.57을 사용한다. 위 검증은 건너뛴 항목 없이 모두 통과했다. 이후 원격 소스를 게시하고 GitHub Actions의 `/`와 `/flip-it/` CI도 모두 통과했다. 데스크톱·모바일 스크린샷 확인은 이전 환경의 기록이며 이번에는 반복하지 않았다. 실제 Pages 게시·사이트 확인은 아래 배포 상태와 구분한다.

- `npm run check`: TypeScript, Vitest 도메인 테스트, Vite 프로덕션 빌드.
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`: 실제 Chromium의 데스크톱 및 360px 모바일 설정.
- 수용 기준 AT-ST-01~12를 중심으로 과목 필터, 설정 진입, 빈 선택 차단, 주제 선택, 복원, 프리셋 초기화, 판정 변경, 비율, 명시적 완료, 단어장 분리, 그림 없음, 가로 넘침을 검증한다.
- 추가 오류 시나리오: 손상된 로컬 데이터 보호, 저장 용량 초과 안내, 이미지 404 대체 설명, 콘텐츠 버전 변경 시 기존 회차 보존. Pages 하위 경로의 실제 이미지 로딩과 직접 새로고침도 검증한다.

## 복원 및 배포 상태

- 기존 `/workspace/flip-it`은 커밋과 작업 파일이 없는 체크아웃이었다. 기존 origin을 유지하고 검증된 번들을 fetch한 뒤 `main`으로 전환했다. 별도 worktree, reset, force push는 사용하지 않았다.
- 복원한 원본 커밋: `81603ab240ebd172e809f247fd9195a530f34841`.
- 원본 트리: `1ce363cec623a716c4b04d1b69a5c57fdd7d4bc9`. `git fsck --full` 통과.
- PRD SHA-256: `a5fd5434475bba4f8836db3c33095a9d90b197c13f708b176aad970dfd46efcd`. PRD와 lockfile은 변경하지 않았다.
- GitHub 연결 도구에서 명시적으로 선택한 `moonsunzoo` 계정은 인증에 성공했고, `moonsunzoo/flip-it`의 `permissions.push: true`, 관리자 권한을 확인했다.
- 실행 환경의 HTTPS Git 인증은 별개다. 쓰기 없는 `git push --dry-run origin main`에서 `Permission to moonsunzoo/flip-it.git denied to mun-seonju`와 HTTP 403이 반환됐다. 원격 ref는 비어 있었으며 실제 push는 수행하지 않았다.
- `gh api user`와 저장소 권한 API 조회는 현재 실행 환경에서 `Forbidden`으로 차단된다. 로컬 네트워크 정책에는 `api.github.com`과 `moonsunzoo.github.io`가 없다. API 실패만으로 CLI 계정을 판정하지 않았으며, 계정 불일치의 근거는 Git 서버의 dry-run 응답이다.
- Git CLI 인증을 변경하는 대신, `moonsunzoo` 연결 도구의 Git 데이터 API로 원격 게시를 완료했다. 최초 소스 게시 커밋은 `ea47a48836924826f9961c37a27c45b2bf17c3d0`이며, 파일 트리 `07f43a3a5cdb30cc06467957b4a16eb9b8596736`는 로컬 복원 검증 커밋 `c738624`와 일치한다. 원본 Git 기록은 첨부 번들과 로컬 `handoff/recovered-main` 브랜치에 보존한다. 원격 게시 과정에서 새 커밋 ID가 생긴 사실을 원본 기록 복원과 구분한다.
- 원격 CI [39774358185](https://github.com/moonsunzoo/flip-it/actions/runs/39774358185)는 성공했다. 두 base 경로에서 각각 포맷·타입·단위 테스트·빌드·브라우저 E2E를 실행했다.
- 최초 배포 실행 [39774358171](https://github.com/moonsunzoo/flip-it/actions/runs/39774358171)은 Pages 설정 조회에서 `Not Found`로 실패했다. 이후 사용자가 저장소 Pages Source를 GitHub Actions로 설정 완료했고, 아래 재배포가 성공했다.
- 배포 커밋 `35647724d3013382117e7282833b30cc0712e473`의 [배포 실행 39775192918](https://github.com/moonsunzoo/flip-it/actions/runs/39775192918)은 build·deploy·verify 모두 성공했다. 21:06 (한국 시간)에 Pages 게시가 완료됐으며, 공개 URL의 HTTP 검사와 실제 데스크톱·모바일 브라우저 테스트 20개가 통과했다.
- 공개 주소는 `https://moonsunzoo.github.io/flip-it/`이다. `/flip-it/` 자산 경로, 해시 화면 이동, 직접 진입·새로고침, SVG 이미지 로딩, 로컬 학습 복원을 공개 사이트에서 검증했다. 클라우드 실행 환경의 외부 접속 제한과 별개로, 이 검사는 GitHub 호스팅 러너에서 공개 주소를 직접 대상으로 실행했다.
- PAT 추가, 기존 계정 삭제, 다른 계정의 collaborator 추가, 프록시 우회나 전역 인증 변경은 하지 않았다. 현재 제공된 환경 도구는 상태 조회만 지원하며, 실행 환경의 Git 계정 선택 원인은 아직 확인되지 않았다.

- 첫 번째 피드백 배포 커밋 `997f0bbb6945a4a89f4a3c5c56ef01e2134aec3d`의 [배포 실행 39778998719](https://github.com/moonsunzoo/flip-it/actions/runs/39778998719)은 build·deploy·verify 모두 성공했다. 21:33 (한국 시간)에 게시됐고 공개 URL HTTP 검사와 데스크톱·모바일 E2E 22개가 통과했다. 새 브랜드, 소개 영역 제거, 단어 전용 기본 표시, 단어장별 50장, 이전 버전 저장 데이터 복원을 포함한다.

- 두 번째 피드백 커밋 `d03a254e6361c873d3dc05433fefc1452b041207`의 [CI 39781439478](https://github.com/moonsunzoo/flip-it/actions/runs/39781439478)은 두 base 경로에서 성공했다. [배포 39781439489](https://github.com/moonsunzoo/flip-it/actions/runs/39781439489)도 build·deploy·verify 모두 성공했다. 공개 주소를 대상으로 한 E2E 28개에는 실제 터치 입력의 좌우 이동·취소·짧은/세로 제스처, 안내 반복 방지, 단계별 설정 보존 및 기존 학습 기록 복원이 포함된다.

후속 원격 변경도 올바른 계정의 연결 도구로 부모 커밋을 확인하고 fast-forward로 게시한다. 배포 워크플로에는 게시 URL을 직접 검사하는 E2E 단계를 추가했다. 배포 결과만 기록하는 문서 커밋은 `[skip ci]`로 중복 배포를 생략하며, 현재 실제 게시 버전은 `d03a254`이다.

## 알려진 제한

- 샘플의 공개 상태는 코드에 동봉된 개발 데이터의 상태이다. 교사 검수·게시를 실제로 완료한 자료라는 뜻이 아니다.
- 현재 이력은 브라우저/사이트 주소별로 분리된다. 중앙 저장, 계정, 기기 동기화는 없다.
- 이력은 단어장당 20회까지 유지한다. 삭제·시크릿 모드 종료·기기 변경 시 복원이 보장되지 않는다.
- 여러 탭에서 동시에 학습하면 마지막 저장이 우선한다.
- 접근성은 기본 키보드 조작·상태 텍스트·대체 텍스트·축소 모션 대응까지 포함한다. 별도 보조 기술 감사, Safari/Firefox 검증은 아직 수행하지 않았다.
- 원격 소스 게시는 `moonsunzoo` 연결 도구를 사용한다. 실행 환경 Git CLI의 계정 불일치는 해결되지 않았으므로 일반 `git push`가 동작한다고 가정하지 않는다.
